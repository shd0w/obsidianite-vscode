## Obsidianite: the original theme

- **Project:** [Obsidianite](https://github.com/bennyxguo/Obsidian-Obsidianite), a theme for [Obsidian](https://obsidian.md)
- **Author:** Benny Guo (Guo Xiang)
- **License:** MIT

**What we use:** this extension is a port of Obsidianite. Its colors and styling come from Obsidianite's CSS:
- the backgrounds (`#100e17`, `#191621`, `#0d0b12`)
- text `#bebebe` and headings `#cbdbe5`
- the cyan `#0fb6d6` and pink `#f4569d` accents
- the blue `#7aa2f7` and purple `#bb9af7`
- how headings, tags, bold, italics, links and code blocks look

Obsidianite Facets also takes the hues of its twelve accents from these colors.

The full license is reproduced at the end of this file.

## Dracula: the syntax colors

- **Project:** [Dracula Theme](https://draculatheme.com) ([VS Code version](https://github.com/dracula/visual-studio-code))
- **License:** MIT

**What we use:** Obsidianite's code-block highlighting uses Dracula's palette:
- `#ff79c6`, `#50fa7b`, `#f1fa8c`, `#bd93f9`, `#ffb86c`, `#6272a4`, `#8be9fd`, `#f8f8f2`

The original **Obsidianite** and **Obsidianite AMOLED** themes keep these colors for syntax highlighting. Facets adjusts these hues for each flavor.

The full license is reproduced at the end of this file.

## Monokai: the property color

`#66d9ef`, used for properties in Obsidianite's code blocks and in the original themes here, comes from [Monokai](https://monokai.pro) by Wimer Hazenberg.

## Catppuccin: inspiration for how Facets is organized

- **Project:** [Catppuccin](https://github.com/catppuccin/catppuccin)
- **License:** MIT

**What inspired us:** Obsidianite Facets follows the approach Catppuccin made popular:
- one palette in several flavors
- named swatches
- a style guide that maps each role to a swatch, so every app port matches

**What we don't use:** Catppuccin's colors, swatch names, flavor names, code or artwork. Facets' palette was calculated separately from Obsidianite's colors, and its names (garnet, tourmaline, aquamarine, Quartz, Jet, …) are our own.

## Fonts on the preview page

The [interactive preview](https://shd0w.github.io/obsidianite-vscode/) loads Bricolage Grotesque, Figtree and JetBrains Mono from Google Fonts. They are under the SIL Open Font License and are not redistributed in this repository.
