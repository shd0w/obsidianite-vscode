Obsidianite Facets

One palette cut six ways. Obsidianite's cyan, pink and violet become twelve named gem accents and a twelve-step neutral ladder, in one light flavor, four dark ones and an AMOLED black. Every app port takes its colors from the same swatch names, so VS Code, your terminal and your notes all match.

Palette notes

          
#themes#todo#ideas

          
Every flavor keeps the same twelve accent names, so a port only says which swatch goes where, never a raw hex. Accents use oklch() lightness steps, so contrast stays even from flavor to flavor.

      Palette
      
Twelve gems, twelve neutrals

      
Each accent keeps the hue of an Obsidianite color. Each flavor sets its own lightness and saturation, so every accent stays readable on that flavor's background.

      Terminals
      
The 16 terminal colors, per flavor

      
These are the exact colors the Ghostty, iTerm2, Terminal.app and VS Code terminal themes use. Programs that print ANSI colors (git, ls, test runners) look like this. The top row of swatches is normal, the bottom row is bright.
